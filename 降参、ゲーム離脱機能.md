# markdown_tmp
mermaid記法を用いたアクティビティ図制作のテストです
## アクティビティ図
## 降参、ゲーム離脱機能

```mermaid
flowchart TD
    initialNode([●]) --> start

subgraph ユーザー
    pushRetireButton(降参ボタンを押下)
    pushRetireButtonYes{確認ウインドウの「はい」を押したか}
end

subgraph システム
    appearYesnoWindow(降参確認ウインドウを表示)
    deleteUserSession(ユーザーをセッションから削除)
    returnInGame(確認ウインドウを消去しゲームに戻る)
    goBackTitle(タイトル画面を表示)
end

start --> pushRetireButton
pushRetireButton --> appearYesnoWindow
appearYesnoWindow -->pushRetireButtonYes
pushRetireButtonYes -- yes --> deleteUserSession
pushRetireButtonYes -- no --> returnInGame
returnInGame --> endWindow([●])
deleteUserSession --> goBackTitle
goBackTitle --> endBack([●])
```
